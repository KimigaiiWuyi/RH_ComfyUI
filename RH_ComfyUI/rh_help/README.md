# rh_help — 帮助模块

## 模块概述

`rh_help` 是 RH_ComfyUI 插件的**帮助子模块**，负责向用户发送使用帮助信息，并将插件注册到 GsCore 的全局帮助一览中。

## 文件结构

```
rh_help/
└── __init__.py      # 帮助命令处理器 + 全局帮助注册
```

## 核心组件

### SV 实例

```python
sv_help = SV("RH_ComfyUI 帮助")
```

### 帮助命令 [`send_help()`](RH_ComfyUI/rh_help/__init__.py:12)

触发关键词：`帮助`（`on_fullmatch`，精确匹配，`block=True`）

发送的帮助内容涵盖：

| 类别 | 命令 | 说明 |
|------|------|------|
| 🖼️ 图片生成 | `生图 [模型名] <描述>` | 文生图/图生图 |
| 🖼️ 图片生成 | `改图 [模型名] <描述>` | 图片编辑（需带图） |
| 🎬 视频生成 | `生视频 [模型名] <描述>` | 文生视频/图生视频 |
| 🎵 音频生成 | `生音乐 [模型名] <描述>` | 音乐生成 |
| 🎵 音频生成 | `生语音 [模型名] <文字>` | 语音合成 |
| 📋 模型信息 | `模型列表` | 查看所有可用模型 |
| 📋 模型信息 | `模型详情 <模型名>` | 查看模型详情 |
| 💰 积分管理 | `查询积分` | 查看当前积分 |
| 💰 积分管理 | `增加积分 <@用户> <数量>` | 管理员加积分 |

### 全局帮助注册

```python
register_help(
    "RH_ComfyUI",
    f"{get_plugin_available_prefix('RH_ComfyUI')}帮助",
    None,  # 使用默认图标
)
```

将插件注册到 GsCore 的「core 帮助」一览页，用户发送 `core帮助` 时会列出所有已注册插件。

## 与其他模块的关系

```
rh_help ──→ GsCore register_help（全局帮助注册）
        ──→ GsCore SV（命令触发器）
```
