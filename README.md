## 丨安装提醒

> **注意：该插件为[早柚核心(gsuid_core)](https://github.com/Genshin-bots/gsuid_core)的扩展，具体安装方式可参考[GenshinUID](https://github.com/KimigaiiWuyi/GenshinUID)**
>
> **如果已经是最新版本的`gsuid_core`, 可以直接对bot发送`core安装插件RH_ComfyUI`，然后重启core以应用安装**
>
>
> 支持NoneBot2 & HoshinoBot & ZeroBot & YunzaiBot的**连接到ComfyUI实例或者连接至RunningHub代理**的聊天机器人插件
>
> 🚧插件目前还在施工中，功能快速迭代中...🚧
>
> 
> ✨如果需要添加其他相关功能欢迎在[issues](https://github.com/KimigaiiWuyi/RH_ComfyUI/issues)中提出✨
